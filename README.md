# Krishna Visa Consultancy Pvt Ltd

Static frontend website for Krishna Visa Consultancy Pvt Ltd.

## Files

- `index.html` — main website
- `css/style.css` — complete styling and responsive design
- `js/script.js` — smooth UI behavior, mobile menu, scroll reveal and back-to-top
- `assets/logo.svg` — temporary KVC logo

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## GitHub

Push the complete folder to a GitHub repository.

## Hosting

This is a static website and can be hosted on GitHub Pages, Netlify, Vercel, S3, or served by Tomcat.

For Tomcat, place the folder under `webapps` and use `index.html` as the entry page.
